# Aturan Format Respons & Kode: Tanpa Emoji dan Emoticon

Dilarang keras menggunakan emoji atau emoticon dalam bentuk apa pun.
Aturan ini berlaku mutlak untuk:
1. Seluruh teks jawaban atau komunikasi kepada pengguna.
2. Penamaan file, folder, dan sheet (tab) spreadsheet.
3. Seluruh baris kode (komentar, log terminal, string literal, label, hyperlink, format teks).
4. Pesan notifikasi Telegram, email, dan template lainnya.
5. Format data output (CSV, JSON, database).

Gunakan bahasa formal, bersih, profesional, dan berbasis teks biasa tanpa ornamen simbol/emoji.
